Notes
*   Cases ran on a local PostgreSQL 16.15 database after the IMS-04.1 migration and seed, on branch Sprint-1.
*   Tests that change data ran inside a block that rolls back, so the database was left unchanged.
*   Run as the table owner, because the application role smartmart\_app is created by the DBA and is not present on the local database. The migration applies its GRANT and REVOKE only when that role exists, so the permission part of TC-DB-092, 093 and 095 stays open until it is tested with that role.
*   TC-DB-109 and TC-DB-110 are new cases added after review of the append-only and SKU-lock triggers.
